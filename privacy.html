Piker Playback Uploader

Privacy Policy

Last updated September 27, 2026

What this is

Piker Playback Uploader ("the tool") is a private application used only by the owner of the Piker Playback YouTube channel to upload that channel's own videos.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

With the channel owner's permission (Google sign-in), the tool uploads the channel's own videos and thumbnails, and reads the signed-in account's channel ID to confirm it is uploading to the right channel. It does not access, collect or store data about any other YouTube user.

What is stored, and where

The tool stores two things, on the owner's computer only: the sign-in token, and a list of the channel's own uploaded video IDs and titles. Nothing is sold, shared with third parties, or sent anywhere other than YouTube.

Deletion and revoking access

The owner can delete the stored token and upload list at any time by deleting the local files. Access can be revoked at any time on the Google security settings page. After access is revoked, stored data is deleted within 30 days.
